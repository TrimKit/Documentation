# Edge Decal

Edge Decal builds a ribbon of new geometry that follows a chain of selected edges, ideal for panel seams, cables, trim strips, and edge highlights.

## Create Edge Decal

Builds a brand-new decal strip mesh along the selected edges, mapped onto the active trim.

## Assign Edge to Selection

Maps the currently selected edges' associated geometry directly onto the active trim without building a separate decal object.

This is the edge-based equivalent of Trim mode's Selected Trim, for workflows where you want the trim applied in place rather than as new geometry.

## Size

Sets how wide the edge decal strip is.

## Push

Same as in Decal Placer: lifts the finished strip off the surface via a non-destructive Push modifier, to avoid flickering against the base mesh.

## Wrap Corners

Toggle labeled **Wrap Corners** when on and **Flat Strip** when off.

- **On:** the decal strip bends smoothly around corners in the edge chain.
- **Off:** corners stay flat and uncreased, producing sharper, more mechanical-looking junctions.
